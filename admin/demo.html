Demo mode. This is a sandbox copy of the CMS for showing the client how adding/editing/removing content works. When you hit Publish, the change is saved to this browser (not the real site or repo) so you can go back to the live page and see it reflected — the live page will show a red banner when it's displaying demo content. Refresh this admin page, or use the banner's reset button on the live site, to clear it. The real editor (once Netlify is set up) lives at /admin/.
